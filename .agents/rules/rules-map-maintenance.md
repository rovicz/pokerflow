# Manutenção do mapa de regras

Toda alteração em uma regra deve atualizar o [mapa de regras](rules-map.md) na
mesma mudança. Adicione uma linha ao criar uma regra, revise a descrição e o
escopo ao editar, corrija o link ao mover ou renomear e remova a linha ao excluir.
A regra vale também para arquivos de instruções fora de `.agents/rules/`.

Antes de entregar, confira se todos os links do mapa resolvem para arquivos
existentes e se cada regra tem uma entrada única.
